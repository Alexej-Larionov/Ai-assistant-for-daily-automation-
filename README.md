## Проект персонального AI-ассистента**

Данный проект реализует персонального Ai-ассистента для улучшения продуктивности, структурированного доступа к данным и автоматизации повседневных задач. На первом этапе реализуется прототип бэкенда с функциональностью интеллектуальной обработки заметок (notes).

Заметка представляет собой объект, содержащий следующие поля:

title — название;

message — основное содержимое;

metadata — структурированная метаинформация;

summary — краткое содержание.

Пользователь может передавать как полностью, так и частично заполненный объект. Единственным обязательным полем является message. Недостающие поля автоматически генерируются с помощью LLM с применением структурированной генерации и ограничений на выходные данные.

## Запуск приложения

Установка зависимостей:

```bash
pip install -r requirements.txt
```

Запуск сервера:

```bash
uvicorn main:app --reload
```

Интерактивная документация API доступна по адресу:
[http://localhost:8000/docs](http://localhost:8000/docs)

## Подключение LLM

При запуске приложение автоматически проверяет доступность локального сервера LM Studio (`http://localhost:1234/v1`).

Если локальный сервер недоступен, приложение переключается на удалённую модель. Для работы с удалённой моделью необходимо передать API-ключ через эндпоинт `POST /api-key`:

```json
{
    "key": "YOUR_API_KEY"
}
```

## Пример использования

Создание заметки — `POST /notes`:

```json
{
    "note": {
        "message": "До 15 декабря подготовить презентацию по результатам исследования.",
        "metadata": {
            "importance": 7
        }
    },
    "generation": {
        "temperature": 0.3,
        "top_p": 0.9,
        "max_tokens": 1024
    }
}
```

Единственным обязательным полем заметки является `message`. Недостающие поля автоматически заполняются с помощью LLM. Параметры генерации необязательны. Если они не указаны, используются значения по умолчанию. Каждой созданной заметке присваивается уникальный идентификатор (UUID).

## Эндпоинты API

| Метод | Маршрут | Назначение |
|---|---|---|
| POST | `/api-key` | Ввод API-ключа |
| POST | `/notes` | Создание и обработка заметки |
| GET | `/notes` | Получение всех заметок |
| GET | `/notes/{id}` | Получение заметки по идентификатору |
